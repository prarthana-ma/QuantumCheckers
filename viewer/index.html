Quantum Checkers replay viewer

Minimal static step-through for a logged game. No build step, no server, no network.

Toy engine. The upstream Cheqqers engine is not integrated (Gate 2 open). Nothing shown here is a reproduced paper result.

Load a replay

Accepts a replay payload written by python scripts/run_baseline.py --replay <path> (.json), or a raw JSONL log (.jsonl) — the first record in the file is used.

How to produce one 
python scripts/run_baseline.py --condition quantum-observe-vs-random -n 12 \
    --replay results/replay_sample.json
